# Liste de contrôle avant lancement

- [ ] Tous les fichiers source et médias de l'archive sont présents dans le dépôt.
- [ ] Lockfile npm/Bun unique et cohérent avec package.json.
- [ ] Installation propre réussie sur environnement vierge.
- [ ] `npm run lint` réussi.
- [ ] `npm run build` réussi.
- [ ] Variables Vercel renseignées sans secret côté client.
- [ ] Supabase configuré et migration corrigée revue.
- [ ] Tests RLS visiteur / acheteur / vendeur / administrateur réussis.
- [ ] Authentification réelle testée.
- [ ] Commande transactionnelle testée.
- [ ] Paiement sandbox et webhook vérifié.
- [ ] Remboursement et idempotence testés.
- [ ] Tarifs et zones de livraison confirmés avec les transporteurs.
- [ ] Suivi de colis et gestion des échecs testés.
- [ ] Tests mobiles et PWA réalisés.
- [ ] Déploiement Preview validé avant Production.
- [ ] Sauvegardes, logs, alertes et procédure de retour arrière configurés.

Aucun élément non vérifié ne doit être coché.
